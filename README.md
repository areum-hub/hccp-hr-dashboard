# HR Decision Analytics Dashboard

## 프로젝트 소개

본 프로젝트는 **연구 주제를 직접 선정하고 연구 기획부터 데이터 분석, 웹 대시보드 구현 및 배포까지 자기주도적으로 수행한 개인 프로젝트**로, 국민대학교 경영대학원 AI·빅데이터 전공의 피플애널리틱스 수업의 기말과제 최종 결과물로 제출하였습니다.

실제 근로자 조사자료를 활용하여 조직신뢰와 의사소통이 직무만족 및 이직 고려 의향과 어떠한 관련성을 갖는지 분석하고, 연구 결과를 HR 실무의 진단과 의사결정에 연결하고자 하였습니다.

**[웹앱 실행하기](https://areum-hub-hccp-hr-dashboard-app-q1b3k8.streamlit.app/)**

## 연구 및 분석 과정

| 단계 | 수행 내용 |
| --- | --- |
| 연구 설계 | 연구질문 설정, 선행연구 검토 및 가설 H1~H6 수립 |
| 데이터 전처리 | 실제 조사 원자료 정제 및 분석 변수 구성 |
| 측정 신뢰도 | Cronbach's α 및 확인적 요인분석(CFA) |
| 기술통계·집단 비교 | 주요 변수의 기술통계, 상관관계 및 집단별 차이 탐색 |
| 다중회귀분석(OLS) | 통제변수 및 기업 단위 군집강건 표준오차를 적용한 주요 가설 검증 |
| 순서형 로짓 | 순서척도에 대한 대안 모형 분석 및 비례오즈 가정 관련 보조 점검 |
| 구조방정식(SEM) | 변수 간 구조적 관계 및 탐색적 간접경로 분석 |
| HR 의사결정 | 신뢰구간, 다중검정 보정 및 기준값 민감도를 고려한 우선 진단 후보 탐색 |

## 주요 연구 결과

- 조직신뢰와 직무만족은 낮은 이직 고려 의향과 관련된 것으로 나타났습니다.
- 의사소통의 독립적인 관계는 분석모형에 따라 방향이 달라지거나 가설과 일치하지 않아 신중한 해석이 필요합니다.
- 집단별 분석을 통해 HR의 우선 진단 후보를 탐색하고, 현장 의견 수렴과 시범 평가 방향을 제안하였습니다.

## 웹앱 구현 및 공개 배포

실제 근로자 조사 원자료로 수행한 연구의 분석 결과를 쉽게 확인할 수 있도록 Python과 Streamlit 기반의 웹 대시보드를 구현하였습니다.

외부 공개 시 원자료 재배포 및 재식별 위험을 줄이기 위해 개인별 응답 데이터와 기업 식별정보를 제외하고, 사전에 산출한 집계 통계와 모형 추정값만 포함하도록 구성하였습니다.

| 구분 | 내용 |
| --- | --- |
| 연구·분석 단계 | 실제 조사 원자료를 활용한 데이터 전처리, 통계분석 및 가설 검증 |
| 공개 배포 버전 | 기존 연구의 집계 통계 및 모형 분석 결과를 표와 그래프로 제공 |

현재 공개 버전에서는 연구 개요와 가설, 측정 신뢰도, 기술통계, 회귀분석, 순서형 로짓, 구조방정식 및 HR 실무 시사점을 확인할 수 있습니다. 집단 분류와 분석 지표, 종속변수 등을 선택하면 해당 조건에 대해 미리 산출된 결과가 표시됩니다. 집단별 평균 비교는 공개 기준(100명 이상·15개 기업 이상)을 충족한 집계 결과만 제공합니다.

**개인별 원자료 조회, 원자료 기반 복합 조건 필터링 및 실시간 통계모형 재추정은 지원하지 않습니다.** 공개 버전은 연구 결과의 시각화와 탐색을 목적으로 GitHub 및 Streamlit Cloud를 통해 배포하였습니다.

## 데이터 출처

- **자료:** 제2차 인적자본기업패널(HCCPⅡ) 제4차(2023) 근로자 조사
- **제공기관:** 한국직업능력연구원(KRIVET)
- **분석 표본:** 공식 근로자 응답 10,759명 중 10,731명(497개 기업)
- [공식 조사 안내](https://www.krivet.re.kr/kor/sub.do?menuSn=18)
- [자료 생성·활용 보고서](https://www.krivet.re.kr/kor/sub.do?menuSn=12&pstNo=PB0000000425)

분석값은 조사자료를 바탕으로 별도로 산출한 연구 결과입니다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 연구의 한계 및 활용 범위

단면 조사자료, 단일문항 측정, 척도의 판별타당성 및 일부 모형 가정의 한계가 있습니다. 분석 결과는 통계적 관련성을 보여주며, 정책의 인과효과나 개인별 이직 위험을 의미하지 않습니다. HR 진단과 후속 검토의 참고 자료로 활용하되 자동화된 인사 결정에 사용해서는 안 됩니다.

원자료는 공개 배포본에 포함하지 않으며, 집계 결과의 공개 가능 범위는 자료 제공기관의 이용조건을 별도로 확인해야 합니다.
