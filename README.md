# HR Decision Analytics Dashboard

HCCPⅡ 제4차(2023) 근로자 조사자료를 바탕으로 산출한 **집계 통계와 모형 분석 결과를 조회하는 Streamlit 대시보드**입니다. 개인별 원자료나 기업 식별정보는 포함하지 않습니다.

**[웹앱 실행하기](https://areum-hub-hccp-hr-dashboard-app-q1b3k8.streamlit.app/)**

## 주요 기능

- **연구 개요·가설:** 연구질문, 이론적 배경, H1~H6
- **데이터 분석:** 측정 신뢰도, 기술통계·집단 비교, 다중회귀(OLS), 순서형 로짓, 구조방정식(SEM)
- **HR 의사결정:** 담당자 및 관심 지표에 따른 집계 결과 조회와 실무 시사점

## 데이터 출처

- **자료:** 제2차 인적자본기업패널(HCCPⅡ) 제4차(2023) 근로자 조사
- **제공기관:** 한국직업능력연구원(KRIVET)
- **[공식 조사 안내](https://www.krivet.re.kr/kor/sub.do?menuSn=18)**
- **[자료 생성·활용 보고서](https://www.krivet.re.kr/kor/sub.do?menuSn=12&pstNo=PB0000000425)**

공식 근로자 응답 10,759명 중 분석에 사용한 공통표본은 10,731명(497개 기업)이며, 분석값은 별도로 산출한 연구 결과입니다.

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 활용 범위 및 유의사항

본 앱은 사전에 계산한 **집계·모형 결과를 시각화**하며, 실시간으로 모형을 재추정하지 않습니다. 관찰자료의 통계적 관련성은 인과효과나 개인별 이직 위험을 의미하지 않으며, 자동화된 인사 결정에 사용해서는 안 됩니다.

원자료의 재배포를 피하도록 구성했으나, 집계 결과의 공개 가능 범위는 별도로 자료 이용조건을 확인해야 합니다.
