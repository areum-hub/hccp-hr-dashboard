# HR Decision Analytics Dashboard

## 프로젝트 소개

본 프로젝트는 **연구 주제를 직접 선정하고 연구 기획, 데이터 분석, 웹앱 개발 및 배포까지 자기주도적으로 수행한 개인 프로젝트**입니다. 국민대학교 경영대학원 AI·빅데이터 전공의 피플애널리틱스 수업에서 수행하였으며, 기말과제의 최종 결과물로 제출하였습니다.

실제 근로자 조사자료를 활용하여 조직신뢰와 의사소통이 직무만족 및 이직 고려 의향과 어떠한 관련성을 갖는지 분석하고, 연구 결과를 HR 실무의 진단과 의사결정에 연결하고자 하였습니다.

연구질문 설정, 선행연구 검토, 가설 수립, 통계모형 분석 및 결과 해석을 진행하였으며, 연구 결과를 보다 쉽게 탐색하고 활용할 수 있도록 Python과 Streamlit 기반의 HR 데이터 분석 및 의사결정 지원 웹앱을 개발하고 배포하였습니다.

사용자는 웹 브라우저에서 주요 통계분석 결과를 확인하고 관심 지표와 집단을 선택하여 HR의 우선 진단 대상과 후속 검토 방향을 살펴볼 수 있습니다.

공개 웹앱은 HCCPⅡ 제4차(2023) 근로자 조사자료에서 사전에 산출한 집계 통계 및 모형 추정값을 조회하는 방식이며, 개인별 원자료나 기업 식별정보는 포함하지 않습니다.

**[웹앱 실행하기](https://areum-hub-hccp-hr-dashboard-app-q1b3k8.streamlit.app/)**

## 웹앱 개발 및 공개 배포

본 프로젝트는 실제 HCCPⅡ 근로자 조사 원자료를 기반으로 데이터 분석을 수행하고, 연구 과정과 분석 결과를 웹 환경에서 탐색할 수 있도록 개발한 개인 프로젝트입니다.

연구용 웹앱 개발 이후 외부 공개 과정에서는 개인정보 보호 및 원자료 재배포 방지를 고려하여 공개 배포본의 데이터 구조를 별도로 구성하였습니다.

| 구분 | 데이터 및 기능 |
| --- | --- |
| 연구·개발 버전 | 실제 조사 원자료를 활용한 데이터 분석 및 연구 결과 조회 기능 구현 |
| 공개 배포 버전 | 개인별 원자료와 기업 식별정보를 제외하고, 사전에 산출한 집계 데이터 및 통계모형 분석 결과를 기반으로 웹앱 서비스 제공 |

공개 배포 과정에서도 기존 연구의 주요 분석 결과와 가설 검증 결과를 유지하였으며, 사용자가 분석 지표와 집단을 선택하여 연구 결과를 탐색할 수 있도록 구성하였습니다.

이를 통해 데이터 분석뿐만 아니라 연구 결과의 서비스 구현, 데이터 보호를 고려한 공개 배포까지 수행하였습니다.

**프로젝트 수행 흐름**

연구 주제 직접 선정 → 실제 조사 원자료 확보 및 전처리 → 통계분석 및 연구 가설 검증 → Python·Streamlit 기반 웹앱 개발 → 공개 배포를 위한 데이터 구조 재구성 → GitHub 및 Streamlit Cloud 배포

## 프로젝트 수행 과정

| 단계 | 수행 내용 |
| --- | --- |
| 연구 기획 | 연구 주제 직접 선정, 실무 문제 정의, 선행연구 검토 및 가설 설정 |
| 데이터 분석 | 실제 조사자료 기반 통계분석, 모형 비교, 결과 해석 및 한계 검토 |
| 서비스 기획 | 분석 결과를 HR 진단 및 의사결정에 활용할 수 있도록 화면과 기능 설계 |
| 웹앱 개발 | Python·Streamlit 기반 분석 결과 시각화 및 사용자 선택형 조회 기능 구현 |
| 배포 및 결과물 제출 | GitHub 소스 관리, Streamlit 웹앱 배포 및 기말 연구 결과물 제출 |

## 연구 및 분석 과정

| 단계 | 분석 내용 |
| --- | --- |
| 연구 설계 | 사회교환이론, JD-R 모형 및 선행연구를 바탕으로 H1~H6 설정 |
| 측정 신뢰도 | Cronbach's α 및 확인적 요인분석(CFA) |
| 기술통계·집단 비교 | 주요 변수의 분포와 상관관계, 집단별 차이 탐색 |
| 다중회귀분석(OLS) | 통제변수와 기업 단위 군집강건 표준오차를 적용한 주요 가설 검증 |
| 순서형 로짓 | 순서척도에 대한 대안 모형 및 비례오즈 가정 관련 보조 점검 |
| 구조방정식(SEM) | 변수 간 구조적 관계 및 탐색적 간접경로 분석 |
| HR 의사결정 | 집단별 차이, 신뢰구간, 다중검정 보정 및 기준값 민감도를 고려한 진단 후보 탐색 |

## 주요 연구 결과 및 시사점

- 조직신뢰와 직무만족은 낮은 이직 고려 의향과 관련된 것으로 나타났습니다.
- 의사소통의 독립적인 관계는 분석모형에 따라 방향이 달라지거나 가설과 일치하지 않아, 척도 간 중첩과 판별타당성의 한계를 고려한 해석이 필요합니다.
- 집단별 분석 결과는 HR의 우선 진단 후보를 선정하고, 현장 의견 수렴과 소규모 시범 평가로 이어지는 의사결정의 참고 근거로 활용할 수 있습니다.

연구 결과는 단면 조사자료의 통계적 관련성을 보여주며, 정책 개입의 인과효과나 개인별 이직 가능성을 확정하지 않습니다.

## 주요 기능

- **연구 개요·가설:** 연구질문, 이론적 배경, H1~H6
- **데이터 분석:** 측정 신뢰도, 기술통계·집단 비교, 다중회귀(OLS), 순서형 로짓, 구조방정식(SEM)
- **HR 의사결정:** 담당자 및 관심 지표에 따른 집계 결과 조회와 실무 시사점

## 활용 범위 및 유의사항

본 앱은 사전에 계산한 집계·모형 결과를 시각화하며, 실시간으로 모형을 재추정하지 않습니다. 관찰자료의 통계적 관련성은 인과효과나 개인별 이직 위험을 의미하지 않으며, 자동화된 인사 결정에 사용해서는 안 됩니다.

원자료의 재배포를 피하도록 구성했으나, 집계 결과의 공개 가능 범위는 별도로 자료 이용조건을 확인해야 합니다.
