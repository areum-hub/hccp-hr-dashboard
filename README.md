# HR Decision Analytics Dashboard | HCCPⅡ 4차(2023)

피플애널리틱스 기말과제 공개용 Streamlit 웹앱입니다. **2023년 실제 HCCPⅡ 자료의 저장된 집계·모형 추정값을 조회하는 앱**으로, 근로자별 원자료나 기업 식별자를 포함하지 않습니다. 전체 연구의 H1~H6 추정값은 원래 분석본과 동일합니다.

## 앱 구성 (사이드바 8개 화면)

**연구 설계**
1. 연구 개요: Executive Dashboard, KPI 4개, 핵심결과 3개 카드, 지표별 평균, HR 의사결정 흐름
2. 이론·연구가설: 사회교환이론·JD-R, H1~H6 가설 도출, 변수·통제·매개·조절, 결과 대조와 대안 설명

**데이터 분석**
3. 01 측정 신뢰도: Cronbach α, 문항별 평균, CFA와 판별타당성 경고
4. 02 기술통계·집단 비교: 공개용 사전 집계에 대한 집단 분류/지표 선택, 관찰 상관
5. 03 OLS: 가설별 B·p·95% CI, 종속변수 선택, H4의 계수 변화
6. 04 순서형 로짓: 누적 오즈비(OR), 신뢰구간, 비례오즈 관련 진단
7. 05 SEM: 적합 경로도, H1~H6, CFI/TLI/RMSEA/SRMR, 간접경로

**의사결정**
8. HR 의사결정: 담당자/관심 지표 선택, 사전 저장된 152개 집단 비교의 기본 선별 결과, 사전 계산된 민감도 조회, 3단계 실행 제안

**연구자료**
데이터 출처·참고문헌·AI 활용·연구윤리는 **연구 개요 화면의 접기/펼치기 영역**과 최종 PDF 설명서에서 확인할 수 있습니다. 모든 분석 페이지 하단에도 원자료의 공식 출처를 표시합니다.

## Windows PowerShell 로컬 실행

```powershell
# ZIP을 압축 해제한 앱 폴더에서
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

또는 ZIP을 압축 해제하고 `run_local.ps1`을 사용하세요. PowerShell 실행 정책이 차단할 경우 앱 폴더에서 `py -m streamlit run app.py`를 직접 실행하면 됩니다.

실행 후 `http://localhost:8501`에서 사이드바 전체 메뉴를 확인합니다. 앱 실행이 안 될 때는 Python 3.10 이상을 사용하는지 확인하세요.

## Streamlit Community Cloud 배포

1. GitHub 저장소를 만들고 **이 배포용 폴더 안의 파일만** 저장소 루트에 업로드합니다. 분석 원본 ZIP, `data.csv`, 원자료가 포함된 HTML은 업로드하면 안 됩니다.
2. Streamlit Cloud `Deploy an app`에서 Repository는 실제 GitHub 저장소, Branch는 실제 사용 중인 브랜치(`main` 등), Main file path는 **`app.py`**로 입력합니다.
3. 생성된 공개 URL을 로그아웃·시크릿 브라우저에서 열어 8개 메뉴, 집단 비교/OLS 선택, HR 담당자/지표 선택, 출처 링크를 확인합니다.
4. 실행 URL은 최종 설명서 `U2026030_고아름_최종.pdf`의 실행 안내와 과제 제출란에 기재합니다. `localhost`는 공개 제출 링크가 아닙니다.
5. 성적 공지 전까지 공개 URL이 정상 작동하는지 주기적으로 확인하세요. 무료 호스팅의 휴면·절전·리소스 정책을 고려해야 합니다.

## 공개 데이터 관련 주의

원자료 자체 및 근로자별 레코드는 포함되지 않았고, 공개 기준을 통과한 미리 계산된 집계 통계만 담았습니다. **그러나 집계 결과를 공개하는 것과 HCCPⅡ 약관상 배포 허가가 있는 것은 별개의 문제입니다.** 기관의 자료 이용 조건을 확인하고 필요시 공개 전에 허가를 받아야 합니다. 출처 표시만으로 외부 공개 권리가 생기지 않습니다.

`python preflight_public.py`는 파일 목록과 주요 통계값을 확인하지만, 법적 허가를 보장하는 것은 아닙니다.

## 분석상의 핵심 제한

- H1–H5의 OLS가 주 분석, 순서형 로짓과 SEM은 보완 분석, H6는 탐색적 간접경로입니다.
- H2는 OLS와 SEM에서 부호가 다르며 H4는 기대와 다른 양(+) 부호입니다.
- SEM의 CFA 판별타당성 문제, RMSEA 약 0.090, 순서형 로짓 직무만족의 경계별 동일성 문제를 설명합니다.
- 관찰자료이므로 인과효과·정책 ROI·직원별 이직 위험을 추정하지 않습니다. 자동 인사결정에 사용해서는 안 됩니다.
- 웹앱은 **원래 분석을 재실행하는 앱이 아닌 결과 조회용**입니다. 새로운 통계 추정은 수행하지 않습니다.

## 구현·테스트

`app.py`/`ui.css`는 Streamlit UI 및 Plotly 차트로 작성됐습니다. Python 구문 검사와 모든 8개 화면 경로에 대한 결과·차트 모의 실행 검사를 진행했습니다. 작성 환경에는 Streamlit 패키지가 없어 실제 서버/브라우저 실행 및 외부 접속 검사는 수행하지 못했습니다. 배포 후 직접 확인이 반드시 필요합니다.

## 사이드바 레이아웃

메뉴 8개를 왼쪽 정렬하고 높이를 축소했습니다. Streamlit 버전에 따른 버튼 구조 차이를 고려해 CSS 선택자를 지정했습니다. 중간 너비 이하에서는 사이드바의 스크롤을 사용하며, 모든 분석 화면 하단의 출처 문구를 유지합니다.
